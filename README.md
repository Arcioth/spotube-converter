## 🚀 Features

- **Multi-Format Support**: Support for Spotify CSV exports and Plain Text lists (generated by AI).
- **Direct Browser Migration**: Runs directly on `music.youtube.com`, bypassing OAuth quota limits.
- **Privacy First**: 100% local execution. No external servers, no tracking.
- **Smart Search**: Intelligent parsing of song names and artists.
- **Automated Batching**: Handles large playlists (thousands of songs) by intelligently batching requests.
- **Auto-Tab Management**: Automatically opens YouTube Music in a background tab if needed.

---

## 🛡️ Security & Privacy

This extension is built with extreme privacy in mind. **No data ever leaves your computer.**

1. **Local Execution Only:** The extension contains no telemetry, no tracking, and connects to no external servers. 
2. **Key Security:** To create a playlist, YouTube Music requires an internal token (`INNERTUBE_API_KEY`) and a cryptographic hash of your `SAPISID` cookie. 
   - The extension securely requests these variables directly from your active `music.youtube.com` tab's memory.
   - The `SAPISIDHASH` cryptography is computed entirely on your local machine using standard Web Crypto APIs.
   - Keys are used immediately and never saved or transmitted.
3. **Permissions:**
   - `tabs`: To check/open YouTube Music in the background.
   - `scripting`: To securely inject the local migration logic.
   - `storage`: To save logs and consent preferences locally.

## 🛠️ Installation

### Chrome / Edge / Brave
1. Open your browser and navigate to `chrome://extensions/`
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** (top left).
4. Select the `spotube-extension/` folder from this repository.

### Firefox
1. Navigate to `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on...**
3. Select the `manifest.json` file inside the `spotube-extension/` folder.

## 📖 Usage

1. **Get your list**:
   - Export your Spotify playlist as a CSV (via Spotube).
   - **OR** Use the AI Prompt inside the extension to generate a list from any AI (ChatGPT, Claude, etc.).
2. **Open Spotube**: Click the extension icon in your toolbar.
3. **Authorize**: Accept the one-time security consent screen.
4. **Migrate**: Paste your data, name your playlist, and hit **Create Playlist & Migrate**!
